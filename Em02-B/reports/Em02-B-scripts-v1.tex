\begin{abstract}
The runner is \texttt{python -m em02b.run\_audit}.
It writes \texttt{results/tables/audit\_manifest.json}
and refuses \texttt{physical\_identified}.
Fifteen tests passed in \(3.28\) seconds after the quadrature
correction.
This note maps each manifest field to the module that computed it.
The retired shared-node sum is not produced by the current runner.
A later immutable file, \texttt{results/runs/row5a\_05485aec7a9a.json},
records the isolated \(5a\) constructions. Gate G2 passes.
Gate G4 does not: the seed integral changes sign under refinement,
so the runner sets \texttt{row\_value\_released} to false.
\end{abstract}

\section{Tests}
\texttt{test\_audit\_v2.py} checks rejection of the physical label,
relative Route~A/B gap below \(5\%\), Gauss refinement move below
\(3\%\), probe agreement to \(10^{-4}\), shrinking mesh residual,
and a nonzero adjoint integral.
The older tests still cover profile moments, isolation predicates,
the manufactured indicator, and the restriction-order gap.
Passing them does not certify the seven component adjoints.
